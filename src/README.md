# Исходный код CRM-системы (Модуль `crm_system_informatika`)

В данной директории расположен исходный код прототипа консольного приложения CRM-системы с интеллектуальной приоритизацией заявок.

## Требования к окружению
* Python 3.10+
* Менеджер пакетов `uv`

## Запуск приложения

### 1. Основной (штатный) запуск
Запуск приложения через зарегистрированный CLI-скрипт менеджера пакетов:
```bash
uv sync
uv run crm-system-informatika
```
### 2. Запуск через модуль Python
Альтернативный запуск напрямую через точку входа пакета:
```bash
uv run python -m crm_system_informatika.main
```
### 3.Проверка качества кода (Линтинг и форматирование)
Проект настроен на соблюдение стандартов PEP 8 с помощью линтера `ruff`:
```bash
# Проверка и автоматическое исправление ошибок
uv run ruff check --fix

# Проверка форматирования
uv run ruff format
```
